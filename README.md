# Fake News Detector

Нейронная сеть для детекции фейковых новостей.

### Задача:

Создать НС для детекции ложных (фейковых) новостей.

### Что использую:

pandas - для работы с датасетом

sklearn - для классификации текста.

Код можно запустить скопировав репозиторий и развернув его в VSCode, Google Colab и пр.
